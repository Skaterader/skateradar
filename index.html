Features

What it does

滑る前に必要な情報が
全部ここにある Everything you need
before you drop in

🌦
リアルタイム天気Real-Time Weather
各パークの現在の天気と8時間予報。雨天時は屋外パークの混雑を自動的に「空き」として補正します。 Live conditions + 8-hour forecast per park. Rain suppression logic auto-marks outdoor parks as empty when wet.
Open-Meteo API
📡
混雑レーダーCrowd Radar
時間帯別の混雑推定値とユーザー自己報告（120分で自動期限切れ）で、行く前に混み具合がわかります。 Time-based estimates plus user self-reports with 120-minute auto-expiry. Know before you go.
Live Reports
📍
距離順ソートDistance Sorting
現在地から近い順に自動並び替え。所要時間も表示。位置情報はデバイス内のみで処理します。 Auto-sorted by distance from your location. Estimated travel time included. On-device GPS only.
On-Device GPS
⛑
ローカルルールLocal Rules
ヘルメット義務・プロテクターレンタル・会員登録の要否など、Googleマップには載っていない情報。 Helmet requirements, pad rentals, membership rules — the stuff Google Maps doesn't tell you.
Hand-Verified
🌐
完全2か国語Bilingual
日本語・英語を完全対応。訪日スケーターも東京ローカルも、同じ情報にアクセスできます。 Full Japanese and English. Built for visiting skaters as much as Tokyo locals.
JP / EN
🛹
スケーターが作ったBuilt by a Skater
全データを現地で確認済み。開発者自身が抱えていた問題を解決するために作られたアプリです。 Every data point verified in person. This solves a problem the developer actually has.
SF × Tokyo
